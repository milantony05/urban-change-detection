## Earlier Bengaluru/Kochi pilot

The vegetation-to-built-up pilot is retained for provenance and as a separate exploratory study. Its [working manuscript](../paper/manuscript_draft.md) and phase records (`phase2_*` through `phase6_*`) document data preparation, weak labels, independent reference review and the limits of transfer. The `gee/` scripts and supporting `urban_change/` modules remain because those records refer to them. This pilot is not the supervised OSCD benchmark and should not be combined with its accuracy scores.
