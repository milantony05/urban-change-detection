# Urban vegetation-to-built-up change detection

A reproducible research project for detecting vegetation-to-built-up land-cover transitions from multitemporal Sentinel-2 imagery. North Bengaluru is the primary study area; geographic holdouts and an independent city will test transfer.

## Research question

How reliably can a compact two-date deep learning model detect vegetation-to-built-up transitions in a city it has not seen during training, compared with spectral and land-cover-map baselines?

The output is a 10 m land-cover change estimate, **not** individual building detection, legal encroachment evidence, a precise conversion date, or a claim of universal transfer.

## Status

**Phase 1 complete. Phase 2 in progress:** public scene inventory is reproducible for North Bengaluru and candidate external-test city Pune. Pilot North Bengaluru composites for 2018 and 2025 passed grid, band and visual checks. Revised final exports with validity counts and scene manifests are pending. No satellite data or trained model is included in Git. See [catalog notes](docs/phase2_catalog.md) and the [pilot inspection](docs/phase2_pilot_inspection.md).

## Roadmap

1. **Setup:** repository, configuration, data protocol, validation command.
2. **Data:** select matched seasonal Sentinel-2 Level-2A composites; inspect candidate test cities; export aligned rasters.
3. **Labels and baselines:** use Dynamic World as a candidate-label aid; independently check test labels; implement NDVI/NDBI and map-difference baselines.
4. **Model:** train a compact two-date U-Net in PyTorch, save weights and inference GeoTIFFs.
5. **Transfer:** geographic holdouts and unseen-city evaluation, calibrated confidence and one controlled improvement if warranted.
6. **Delivery:** maps, demo, error analysis, reproducible figures and manuscript material.

Each phase should produce a usable checkpoint. Model results will be compared with a held-out, manually checked reference, never evaluated solely against labels generated by the same land-cover product.

## Quick start

Python 3.10 or later is recommended. Phase 1 uses only the standard library.

```bash
git clone https://github.com/milantony05/urban-change-detection.git
cd urban-change-detection
python -m venv .venv
# Linux/macOS: source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m urban_change.config --config configs/study_areas.json
python -m urban_change.catalog --config configs/study_areas.json --output data/catalog_manifest.json
```

Inspect local GEE exports with:

```bash
pip install -r requirements-geospatial.txt
python scripts/inspect_rasters.py path/to/2018.tif path/to/2025.tif
```

The reproducible GEE export is in `gee/export_composites.js`.

## Layout

- `configs/study_areas.json`: candidate study areas, periods, and split roles.
- `urban_change/config.py`: standard-library configuration validator.
- `docs/data_protocol.md`: imagery, labels, split and provenance rules.
- `data/`: local inputs and outputs, ignored by Git.
- `outputs/`: local model artifacts and maps, ignored by Git.

## Data sources

Copernicus Sentinel-2 Level-2A surface reflectance is the planned imagery source. Dynamic World land-cover probabilities can suggest candidates for annotation but do not constitute independent truth. See [data protocol](docs/data_protocol.md) for source links and safeguards.
